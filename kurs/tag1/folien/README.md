# Folien Tag 1

Die Foliensätze von Tag 1 zum Nachlesen. Im Browser öffnen, am besten mit
**«Tag 1 · Übersicht.html»**: Ein Klick auf eine Karte öffnet den Foliensatz dieser Sitzung.

- Blättern mit den Pfeiltasten, `Esc` zeigt alle Folien einer Sitzung.
- Screenshots lassen sich anklicken und vergrössern; wo es ein Original gibt (Cockpit, Brief,
  Präsentation), öffnet «Original öffnen» die Datei selbst.
- Die Folien funktionieren ohne Internet, nur die Schriften kommen aus dem Netz.

Die Folien des Einführungsvortrags sind nicht Teil dieses Downloads.
